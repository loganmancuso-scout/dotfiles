# Dotfiles (work)

Work-machine system configuration managed with [chezmoi](https://www.chezmoi.io).
This repository targets a single macOS work laptop and Scout Motors identity/access
profile.

## Overview

Files use chezmoi's naming convention: a leading `dot_` becomes a leading `.`
when applied to `$HOME` (for example, `dot_config/nvim/` becomes
`~/.config/nvim/`). Files ending in `.tmpl` are Go templates rendered when
chezmoi applies the configuration.

The configuration is intentionally macOS-only. There are no Linux or
Android/Termux OS branches, packages, or fallback paths.

## Install

```bash
sh -c "$(curl -fsLS get.chezmoi.io)"
chezmoi init --apply git@github.com:loganmancuso-scout/dotfiles.git
```

This clones into chezmoi's default source directory,
`~/.local/share/chezmoi`.

## SSH key material

Every entry under `private_dot_ssh/` carries chezmoi's `private_` attribute,
so `~/.ssh` renders with restrictive permissions. Any new file added there
needs the `private_` prefix.

`private_dot_ssh/private_authorized_keys` is an unconditional public-key
listing. `private_dot_ssh/private_1Password/private_config` is generated by
1Password and included from `private_dot_ssh/private_config.tmpl`; do not edit
it by hand.

`~/.ssh/known_hosts` is deliberately not managed because SSH rewrites it as
new hosts are contacted. Private keys are local secrets and are blocked by
both `.gitignore` and `.chezmoiignore`.

SSH authentication and Git commit signing use the macOS 1Password SSH agent.

## Day-to-day

```bash
chezmoi diff      # preview changes
chezmoi apply     # apply source -> $HOME
chezmoi re-add    # pull local $HOME changes into the source repo
chezmoi cd        # enter the source directory
```

Chezmoi copies files rather than symlinking them. Run `chezmoi re-add` when an
application has intentionally changed a managed file and that change should be
preserved in the repository.

## AWS SSO

`dot_aws/config` contains Scout Motors AWS account profiles sharing one
`sso-session` named `ScoutIT`:

```bash
aws sso login --sso-session ScoutIT
aws --profile <name> ...
```

## Pi agent configuration

`dot_pi/agent/` contains the Pi configuration, extensions, agents, prompts,
and skills used by the work laptop. MCP authentication resolves at runtime via
1Password CLI, GitHub CLI, or OAuth; credentials are not stored in this repo.

After applying, install the extensions that have npm dependencies:

```sh
for ext in web-fetch browser; do
  (cd ~/.pi/agent/extensions/"$ext" && npm install)
done
```

The browser extension uses the installed Google Chrome application through
Playwright's `chrome` channel; it does not download a separate browser binary.

Install the pinned Nutanix MCP server once:

```bash
~/.pi/agent/scripts/install-nutanix-mcp.sh
```

## Prerequisites

```bash
# chezmoi
sh -c "$(curl -fsLS get.chezmoi.io)"

# Git LFS
git lfs install

# macOS tools
brew install eza bat fzf tmux colima docker awscli
```

TPM and the Catppuccin theme are fetched automatically by chezmoi externals.
After applying, open tmux and press `prefix + I` once to install the remaining
plugins.
