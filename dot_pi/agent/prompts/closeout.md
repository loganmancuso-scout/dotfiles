Close out this session. Work through these steps in order and report results as you go.

## 1. Git status

- `git branch --show-current` — what branch are we on
- `git status --short` — any uncommitted changes
- `git log --oneline main..HEAD` (or the current branch's merge-base) — commits not yet on `main`
- Check whether the current branch is merged into `main`: `git merge-base --is-ancestor HEAD main && echo merged || echo not-merged` (interpret carefully — this checks if HEAD is an ancestor of main, i.e. already merged)
- Check whether the branch is pushed and in sync with its upstream: `git rev-parse --abbrev-ref --symbolic-full-name @{u} 2>/dev/null` then `git status -sb` or `git log @{u}..HEAD` / `git log HEAD..@{u}` to see ahead/behind counts

Report clearly:
- current branch name
- clean or dirty working tree
- merged into `main`: yes/no
- pushed to upstream: yes/no, and ahead/behind counts if diverged

If there are uncommitted changes, unpushed commits, or no PR open yet, stop and ask whether to run `/commit`, push, and open a PR before continuing — do not do this automatically.
